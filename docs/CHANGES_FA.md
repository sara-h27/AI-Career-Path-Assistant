# اصلاحات نسبت به dialogue.zip اولیه

| یافتهٔ بررسی | اصلاح در نسخهٔ تحویل |
|---|---|
| پایان خودکار با پروفایل ناقص | جداسازی assessment_finished از is_complete؛ هیچ سطحی به‌علت اتمام نوبت حدس زده نمی‌شود |
| شمارش پیام به‌جای سؤال | شمارندهٔ مستقل question_count؛ سؤال‌های فارسی قطعی و سقف ۶ |
| حلقه برای کاربر بدون مهارت | skills_assessed مستقل از آرایهٔ دانسته‌ها |
| پذیرفتن سطح دلخواه و سابقهٔ منفی/NaN | Literal و محدودیت عدد متناهی، نامنفی و strict |
| خروجی None یا خرابی مدل | قرارداد ExtractionResult و رد خروجی نامعتبر پیش از به‌روزرسانی اسلات |
| خطای runtime کتابخانهٔ فارسی | بازگشت به Regex حتی در خطای ساخت/اجرای Hazm |
| استفادهٔ پنهان از تاکسونومی Mock | تاکسونومی الزامی و صریح؛ بارگذاری نامعتبر fail closed |
| نادیده‌گرفتن aliases فایل | نگاشت aliases واقعی با رد ابهام و تطبیق دقیق |
| ورود مهارت واقعی ولی بی‌شاهد | شاهد دقیق از پیام فعلی + کنترل مفهوم، نفی، شنیدن نام و هدف یادگیری |
| نشت نام‌های حذف‌شده به profile_json | خروجی عمومی پاک و فقط کدهای هشدار ثابت |
| ادعای بازسازی گراف بدون فراخوانی | اجرای واقعی GraphEngine پس از تأیید و بررسی کامل قرارداد |
| باقی‌ماندن تأیید/گراف پس از اصلاح | افزایش revision، حذف خروجی قبلی و تأیید مجدد |
| نبود ConversationManager/message | رابط نهایی و قرارداد JSON نسخهٔ ۱٫۰؛ property قدیمی bot_message برای پایتون |
| نبود تسک ۵ | خلاصه‌ساز قطعی فارسی از دقیقاً همان خروجی گراف |
| تست صرفاً چاپی | تست assertion برای هسته، HTTP adapter و Streamlit AppTest |
| نبود بستهٔ اجرا | UI فارسی، requirements، اسکریپت ویندوز/Linux، تنظیمات API و مستند اتصال تیم |
| نبود کنترل مصرف | یک تماس برای هر پیام، بدون retry خودکار، شمارش usage و سقف محافظه‌کارانهٔ نشست |

رابط HTTP از Chat Completions سازگار استفاده می‌کند و وابستگی به OpenAI SDK حذف شده است. خلاصه‌ساز و سؤال‌ها مولد آزاد نیستند؛ مدل فقط استخراج ساختاریافته انجام می‌دهد. این تصمیم کنترل سقف سؤال و انطباق متن/گراف را قابل‌آزمون می‌کند.

سازگاری کامل با کد قدیمی بدون تغییر وجود ندارد: سازندهٔ ماشین حالت اکنون client و guardrail صریح می‌خواهد؛ added_concepts/removed_concepts شامل concept_id و evidence هستند؛ خروجی JSON از message استفاده می‌کند. نمونه‌ها و قرارداد جدید همراه بسته‌اند.

## نسخهٔ ۱٫۰٫۱

پشتیبانی مستقیم native Gemini مطابق مستند متیس اضافه شد. نسخهٔ قبلی صرفاً OpenAI-compatible بود و تغییر Base URL به‌تنهایی برای مسیر مستندشدهٔ Gemini متیس کافی نبود. تنظیمات آماده در `.env.metis.example` و انتخاب پروتکل در UI موجود است. ۵۵ تست پاس شدند؛ اتصال با کلید واقعی کاربر انجام نشده است.
