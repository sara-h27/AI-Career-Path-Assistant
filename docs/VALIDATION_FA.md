# گزارش بررسی نسخهٔ تحویل — ۲۹ اکتبر ۲۰۲۶

## نتیجهٔ اجرا

**۵۵ تست خودکار پاس شدند؛ شکست و خطای تست: صفر.** خروجی اجرای واقعی در `test_results.txt` همراه بسته است. اجرای تست در Python 3.12.14، Streamlit 1.66.1، Pydantic 2.14.1 و HTTPX 0.28.1 انجام شد. اسکریپت‌های CMD برای ویندوز آماده شده‌اند؛ اجرای بومی ویندوز در این محیط انجام نشده است.

| لایه | بررسی |
|---|---|
| مکالمه | مسیر عادی شش سؤال، پرش اسلات، پایان ناقص، نبود مهارت، تأیید منفی، پس‌گرفتن تأیید و جداسازی نشست |
| داده | سطح نامعتبر، عدد منفی/نامتناهی، ورودی خالی/بزرگ، فرم نامعتبر و عدم نشت مفاهیم حذف‌شده |
| شاهد مهارت | شاهد نامرتبط، مهارت ساختگی، نقل ناقص برای پنهان‌کردن نفی/شنیدن نام، هدف یادگیری |

آزمون HTTP با MockTransport انجام شده است؛ هیچ تماس به مدل واقعی یا هزینهٔ API در فرایند ساخت بسته ایجاد نشده است. نام مدل پیش‌فرض، نمونهٔ قابل‌تغییر است و پشتیبانی آن از سوی درگاه شما تأیید نشده است.

## بررسی رابط در مرورگر

Streamlit محلی اجرا شد و endpoint سلامت پاسخ ۲۰۰ داد. در Chromium، نمونهٔ کامل اجرا و تب‌های گراف/خلاصه و فرم پروفایل باز شدند. تصویر گراف و فرم برای بررسی داخلی دیده شد؛ خطای Streamlit در صفحه صفر بود. در سناریوی تحلیلگر داده جونیور بدون مهارت، گراف چهار گره داشت و ترتیب/روابط خلاصه با آن یکسان بود. تصاویر بررسی داخلی همراه بسته توزیع نشده‌اند.

## مواردی که هنوز باید روی سیستم تیم سنجیده شوند

- نصب در ویندوز و دسترسی شبکهٔ همان دستگاه به درگاه.
- معتبر بودن کلید، Base URL، نام مدل و قالب JSON پشتیبانی‌شده.
- کیفیت استخراج واقعی، مخصوصاً نفی، جمله‌های چندمهارتی، تغییر هدف و بیان محاوره‌ای.
- زمان پاسخ واقعی و نرخ هزینهٔ درگاه؛ تست Mock شاهد رسیدن به SLA زیر ده ثانیه نیست.
- بارگذاری تاکسونومی نهایی تیم و آداپتر موتور گراف آن‌ها. موتور مرجعِ قابل‌اجرا تحویل شده است، اما اتصال به پیاده‌سازی دیگر اعضا تا دریافت آن قابل‌آزمون نیست.
- لینک‌های تأییدشدهٔ منابع آموزشی و Module B در دامنهٔ این بسته نیستند.

## سنجش دستی پیشنهادی با API

یک نشست تازه برای هر سناریو باز کنید: کاربر کاملاً مبتدی، بک‌اند با دو سال تجربه و بدون سطح اعلام‌شده، کاربری که فقط اسم SQL را شنیده، کاربری با دو مهارت مثبت و یک مهارت منفی، و اصلاح «اکسل بلد نیستم» پس از تأیید. خروجی JSON و زمان/توکن را از تب قرارداد تیم دریافت کنید؛ کلید را در گزارش نگذارید. نمونه‌ها باید مصنوعی یا با رضایت صاحب داده باشند.

کیفیت معنایی یک مدل زبانی با تست‌های deterministic این بسته تضمین نمی‌شود. کنترل شاهد محافظه‌کارانه است و فرم دستی برای اصلاح ردشدن بیان‌های پیچیده در دسترس است.

## تغییرات نسخهٔ ۱٫۰٫۱: Gemini / متیس

هشت تست native Gemini اضافه شد: مسیر و هدر متیس، نگاشت پیام‌ها، JSON mode، پاسخ schema، نادیده‌گرفتن بخش thinking، شمارش توکن‌های thinking، مسدودشدن/خروجی بریده، دادهٔ خراب، اعتبار مدل/پروتکل، جلوگیری از v1beta تکراری و مسیر کامل استخراج تا گراف. این بررسی‌ها با MockTransport انجام شدند؛ صحت کلید و مدل فعال حساب متیس آزمایش نشده است.
