# Dialogue AI — Persian Career Assessment

راهنمای کامل نصب، API، تست و ارائه: [README_FA.md](README_FA.md).

Windows: `01_setup.cmd`, then `02_run.cmd`.

macOS/Linux: `bash run.sh`.

Offline demo is the default. No API key is included.

Metis Gemini: copy `.env.metis.example` to `.env`, enter your key and the exact enabled model ID. This requires version 1.0.1.
